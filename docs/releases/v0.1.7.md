# vp-cursor-portal v0.1.7

Diagnostic release for field monitoring of Windows display remapping.

## Assets

- `vp-cursor-portal-setup.exe`: Windows installer that installs under `Program Files`.
- `vp-cursor-portal-win-x64.zip`: self-contained portable Windows x64 build.

## Diagnostics

- Adds detailed monitor identity data to display refresh logs when Windows provides it:
  - source adapter and source id,
  - target adapter and target id,
  - output technology,
  - connector instance,
  - EDID manufacturer and product code,
  - monitor friendly name,
  - monitor device path.
- Logs a possible runtime display remap when the same Windows rectangle appears under a different `DISPLAYx` name since the previous refresh.
- Logs a possible saved-layout display remap when a saved layout rectangle now matches a different current `DISPLAYx` name.
- Remap diagnostics explicitly say that no layout changes were applied.

## Compatibility

- Existing `%AppData%\vp-cursor-portal\config.json` files remain compatible.
- Existing layouts, profiles, aliases, and saved display history are not migrated or rewritten by this release.
- Cursor routing behavior remains unchanged.
- The app does not automatically rebind or rename saved layout zones in this release.

## Validation

- Added regression coverage that verifies a possible saved-layout display remap is logged without changing the saved zone id.
- Run `git diff --check` before release tagging.
- Full local `dotnet test` was not run on the development machine because no .NET SDK is installed there.

## Install Notes

For most users, download and run `vp-cursor-portal-setup.exe`.

When replacing an existing install, keep `%AppData%\vp-cursor-portal\config.json` if you want to preserve current field configuration.

Use the ZIP artifact only when you want a portable folder without installer registration.

The installer and executable are not code-signed yet, so Microsoft Defender SmartScreen may show an unknown publisher warning.
